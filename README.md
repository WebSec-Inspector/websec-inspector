# WebSec Inspector

> Plataforma de análise de segurança de aplicações web — Fábrica de Software

## Como rodar

```bash
cp .env.example .env
docker compose up --build -d
```

Acesse:
- App: http://localhost:3000
- API Docs: http://localhost:8000/docs
- RabbitMQ: http://localhost:15672 (guest/guest)
- MinIO: http://localhost:9001 (websec/websec-websec)
